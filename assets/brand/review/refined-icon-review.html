DNACode 图标方案 — 复审与补件说明

现有精修版（v1）· 已完成工程集成 · 本次需要：第二意见 + 3 件补件

产品：DNACode，极简桌面代码编辑器（Windows / macOS / Linux，Tauri 2 构建，MIT 开源）。目标用户是开发者。

图标概念：DNA 双螺旋呼应产品名「DNACode」；深色圆角方块底（桌面应用图标通行做法）；主色 #4C8DFF 与应用主题色一致。

现状：该精修版已集成完毕并通过工程验证——全平台应用图标（Windows exe / 安装包、macOS icns、Linux png）与应用界面内小标（工具栏 / 欢迎页 / 空状态）均已替换；16px 可读性与打包一致性做过逐像素与字节级验证。

本次请你：① 复审，给出第二意见（哪些成立、哪些你会改）；② 完成第四节列出的补件。

一、方案速览与关键规格

画布1024 × 1024（SVG 母版 + PNG 导出）
底板圆角正方形，圆角半径 180；渐变 #1B2230 → #10151E；描边 #2B3547
后链#315FA8（实色，非透明叠加），线宽 68，圆头
前链#4C8DFF，线宽 68，圆头；绘制顺序：后链 → 横档 → 前链（压住横档近端）
横档 ×2母版 #4C8DFF 线宽 42；小尺寸版 #8DB7FF 且覆盖双链（保证 16px 下可读）
尺寸策略16 / 24 / 32px 使用专用简化几何（非缩放）；48px 以上使用母版导出

二、请你重点验证的 5 件事

  1. 小尺寸 16 / 24 / 32（本方案最花心思的部分）。 下图左半是打包进 exe 后从真实文件中提取的 16px / 32px，右半是对照的设计源。如果你的环境是 Windows：包内的安装包双击安装后，可直接查看任务栏 / 开始菜单 / 资源管理器的实际效果。
    真实构建产物提取（左）×10 放大 vs 设计源（右）
  2. 背景理解：为什么小尺寸必须用专用几何。 实测把 1024 母版直接缩放：16px 的横档结构会完全消失（下图左）；专用几何（右）维持了梯子可读性。
    单一源转换（左）vs 艺术指导小尺寸（右）
  3. 应用内小标（工程侧按规则派生，未经设计过目——重点求确认或修改）。 规则：≤ 32px 用「小尺寸几何」，≥ 36px 用「母版几何」；深色主题 后链 #315FA8 / 横档 #8DB7FF；浅色主题 后链 #9AB9EB / 前链与横档 #2563EB（呼应浅色变体）。
    应用内小标现状：深色主题（上）/ 浅色主题（下），含实际尺寸与放大对照

    上：旧版；中：精修版；下：精修版在深色背景。均 ×10 放大
  5. 浅色 / 单色变体（已随套件交付，请确认用法与质量）： 深色底用深色版、浅色底用浅色版；单色版目前是「白标 + 深底」。

三、当前字标的问题（补件 1 的原因）

字标文字填充 #E6E9F0 只适配深色背景；在浅色背景（例如 GitHub 浅色主题）上文字几乎不可见：

现有字标渲染在浅色背景上的实际效果

四、需要你产出的补件（3 件）

  1. 浅色版字标：深色文字版本，画布与结构同现有 DNACode-wordmark.svg（760 × 180，横向图标 + 文字组合）。
  2. 字标文字转曲（outline）：现有字标是实时文字（依赖 Inter / Segoe UI 字体栈），在无这些字体的环境字形会漂移；转曲后任何环境字形一致。
  3. （可选）透明底单色图形：配合上面的问题，若你认为需要。

可选加分项：Windows 安装向导头图 150 × 57（BMP，用于安装程序顶部）——非必须。

五、工程约束（避免返工）

  • 交付格式：SVG 源文件（路径尽量精简——界面内会以 20px 内联使用） + 1024 × 1024 PNG 导出。
  • 保持尺寸策略：≤ 32px 用简化几何、≥ 48px 用母版；若要调整策略请附各尺寸示意说明。
  • 颜色请给 HEX 值；不要用透明度表现「后链」（小尺寸会发灰，已实测）。
  • 图形需在 16px 下可辨认（这是我们最看重的验收标准）。
  • 授权：用于 MIT 开源项目，随安装包在 Windows / macOS / Linux 分发。

六、文件与查看方式

  • 品牌套件/：全部 SVG 源文件 + 各尺寸 PNG 导出 + 浅色 / 单色变体 + 字标 + BRAND-GUIDE.md（v1 原始说明文档；个别文字表述与实际文件有细微出入，以实际文件为准）。
  • 平台图标-已集成/：当前实际打包进应用的文件（.ico / .icns / .png），可直接查看。
  • DNACode_0.1.0_x64-setup.exe：Windows 真机查看用（可选，双击安装即可看到任务栏 / 开始菜单效果）。

回传方式：修改后的 SVG / PNG 直接回复文件即可；文字意见用任何形式都行。

本说明中的图片已全部内嵌（base64），单文件即可阅读与转发，无需解压其它素材。
