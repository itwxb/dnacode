No accounts, no telemetry

The app does not include accounts, behavioral analytics, or background uploads.

AI calls require confirmation

Review the file list and content size before confirming an AI request.

Credentials stay in system storage

AI API keys are stored in the operating system credential store, not ordinary config files.

Redaction with human review

Suspected secrets are redacted where possible; you still decide whether to send the content.

AI is a tool,
not a silent observer.

DNACode does not quietly analyze your code in the background. AI is optional: a request is made only after you initiate the action, review the changes to be sent, and confirm it.

Frequently asked questions.

Read the full documentation ↗
Is DNACode a replacement for VS Code?

No. It deliberately omits LSP, debugging, terminal, and extensions. Its focus is quick code browsing and editing, Git review, and a controlled commit-and-push workflow.

Do I have to use AI?

No. AI change summaries are optional. File browsing, code editing, and Git operations work without AI configuration. AI is called only after you initiate the action and confirm the content.

Which models or services does AI use?

It needs a service compatible with the OpenAI Chat Completions API. Enter a Base URL, model name, and API key in settings; the key is stored in the operating system credential store.

Where can I download it or read setup instructions?

Download the latest release from GitHub: Windows x64 (.exe), macOS Apple Silicon (.dmg), and Linux x64 (.deb / AppImage). The repository README also documents per-platform build and installation notes.

Can DNACode run Git Pull or Fetch?

The current version does not include fetch/pull. It focuses on reviewing local changes, staging, committing, and pushing. If the remote has new commits, sync in your terminal first, then return to DNACode.
